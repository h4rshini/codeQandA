    A chunking bug hid the settings

    The search model only reads the first 256 tokens of each piece of code, and 26% of pieces were longer. Everything in the settings file after line 23 was invisible, so the agent could name a threshold but never find its value. Splitting pieces to fit fixed all four affected questions.

    The first grader was too generous

    An AI grader first scored the baseline at 100%, including answers missing the number the question asked for. A strict keyword check caught it. Both checks are reported, and both runs were graded under the same rules.

    Its confidence doesn't mean much yet

    The agent said "high confidence" on all 40 answers, including the ones it got partly wrong. Making confidence reflect what it actually verified is the next thing to fix.
